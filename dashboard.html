Exceptions Queue

Field Submissions (from Toolbox)

JobTypeWhenWhoSummary
Read directly from this browser's local storage, written there by the Toolbox app's Submit buttons. This does not go through Make.com, and it only fills in when both files are served from the same domain and used on the same device or browser, see the Known Limitation note above. Rows are matched to a job on an exact match only (job name, or the Toolbox Job Label set on that job's Source IDs), unmatched rows show the raw text from the Toolbox instead of a guess.

Live Feed (via Make.com)

JobTypeWhenWhoSummary
Pulled over the network from the endpoint Make.com writes to (see MAKE_FEED_URL near the top of the script), not from local storage. Works across devices, unlike the same-device Toolbox bridge above. Rows are matched to a job the same way: exact match on job name or the Toolbox Job Label under Source IDs.

PM Action Queue

TitleOwnerDueStatusJob / WorkstreamNote
Reuses the Engagement Tracker's item schema and click to cycle status pattern as is (id, title, owner, due, status, workstream, note, timestamp). Click Add Action Item to create a real one; nothing is pre-filled.

Roadmap

v0.5 (this tier): single file, manual entry, shared job record model, still local browser storage only.
v0.10: added a same-device Field Submissions bridge from the Toolbox app (local storage, not a network sync, not Make.com). Do not treat this as the v1.5 shared source below, it only works when both files share a browser and a hosting domain.
v1: structured CSV import (JobTread jobs/tasks/schedule export, ControlQore cost export, field checklist tool export, bid vs actual analyzer output). Field observation metrics (lineout, materials) stay manual because they originate in the field, not in a system.
v1.5: a real shared data source so Zach's and Tanner's entries are the same record, not separate unsynced copies. This is also where a real cross-device Toolbox to Dashboard sync belongs, not the v0.10 same-device bridge.
v2: direct system connections (JobTread API, Manus portal, ControlQore) once access matures. The planned PM auto scheduler, if built, becomes the live feed for the lineout tile at that point, not before.
